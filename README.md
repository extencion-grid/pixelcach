# PixelCatch

Extensión Chrome MV3 para detectar y guardar imágenes dinámicas con galería previa.

## Instalación
1. Abre `chrome://extensions`
2. Activa Modo desarrollador
3. Carga carpeta `pixelcatch` con Cargar descomprimida

## Atajos
- `Alt+Shift+S` guardar imagen bajo cursor
- `Alt+Shift+B` abrir galería

## Funciones
- Detección en vivo multi-frame con MutationObserver
- Menú contextual PNG/JPG/WebP/AVIF
- Sidepanel con selección, descarga en carpeta o ZIP
- Opciones de formato, tamaño mínimo y plantilla
